# 换桩期间的计量和运维交付

本地演练资料使用虚构的实物、机构和记录编号。经营单据存放于 `data/`，包括 `switch.json`、`bridges.json`、`account.json`。来源原件在提供时由资料端送出。

## 资料约定

所有时刻是北京时间，表底是十进制定点千瓦时，读数区间左闭右开。分表置零、换序与表关系见施工单。bridges 可确认来自两端的同一业务片段，证据被撤回即取消合并许可。施工和归档的有效范围以 data 中原件为准。结算按表段登记，账务回条冻结金额和当时证据版本。日账档案中 next 为空才表示该份列出的日账领完。

根路径列出资料入口。各路径每次请求依次返回该路径的演练响应，最后一条响应保持不变。不同路径有各自的请求计数。重启资料端从首条响应开始。路径清单中的链接相对同一服务。非演练路由的原件对应 `originals/` 下同名路径，经营单据也可以从 `/data/文件名.json` 直接领取。

## 运行资料端

运行依赖为 Python 3.11 标准库。

```sh
python3 source_service.py --port 8040
```

以下命令核对本地资料服务和交互。

```sh
python3 -m unittest discover -s tests -v
```
